# 接口审计 · Interface Audit

> **一套把「社会关系」当作可清点的接口来处理的分析框架。**
> 不解释意义，只算结构：谁被插在哪些接口上、哪个接口握着母口、每根接口拔掉要付多少。

---

## 一句话

**人的处境，取决于他被迫接入了哪些接口、哪个接口握着母口、以及每根接口拔掉要付多少代价。**

由此可以回答三类问题：

- 一个人／一群人为什么离不开某个处境
- 一个制度为什么改不动、改了还是老样子
- 一次崩解为什么是「总崩」而不是慢慢散

## 这是什么

- **一套判据库**：73 条可反驳的判断规则，每条带「表述／机制／操作判据／边界」
- **一套清点工序**：列接口清单 → 找母口 → 算插拔成本 → 查谱系 → 判悬置
- **一个可以装进 AI 助手的技能**（见下）

## 这不是什么

| 不是 | 为什么 |
|---|---|
| 不是一个万能解释框架 | 用接口解释一切，它就变成了新的拜物教。**律可以加，根不能丢。** |
| 不是道德判断 | 它解释「为什么」，不判「好不好」。 |
| 不是行动指南 | 它说明约束在哪，不说明该做什么——后者需要价值判断，本框架不提供。 |
| 不是学术著作 | 没有文献综述与学派定位，只有判据与边界。 |

## 核心概念（五个词）

| 词 | 意思 |
|---|---|
| **接口** | 一段社会关系。**接口是关系，不是实体**——土地、资本、劳动是载体，不是接口本身。 |
| **母口** | 在核心资源的生产或分配关系中占支配地位的那根。**生产型**以「占有」为标志，**分配型**以「卡口」为标志。 |
| **插拔成本** | 接入、维持、拔除三笔账。**自由不是心态，是插拔成本的函数。** |
| **悬置** | 旧口已拔、新口未成。断档期的焦虑，是接口结构问题，不是性格问题。 |
| **联保度** | 拔掉 A，B 会不会同时失效。**联保把单根成本放大成总成本。** |

## 一个最小示例

某平台的商家明知抽成高，为什么还是不走？

- **母口**＝流量入口（分配型）。抽掉它，评价、履约、贷款三根口同时失效。
- **插拔成本**：单根不算高，但**联保度高**——所有子接口都指向同一个流量坐标，拔一根则其余同时贬值。
- **结论**：不是商家不理性，是**联保结构把单根成本放大成了总成本**。
- **反驳条件**：若出现第二个同等流量的入口、且评价可跨平台迁移，这个结论就不成立。

**写出反驳条件，结论才算成立**——这是本框架的写作纪律。

## 这套东西从哪来

它长在三支脉络上：

1. **马克思**关于「人的本质是一切社会关系的总和」的命题，以及生产关系、剩余价值与地租的分析；
2. **列宁**关于帝国主义、国家与暴力的分析，以及米歇尔斯关于组织寡头化的论断；
3. **当代中国民间思想场域**——若干长期参与社会观察与讨论的写作者，在关于成本、分配、政策与产业的分析中提出的判断。

第三支的思想增量，其观点已经过提炼与改写，**表述一律做了匿名化处理**；本框架不代任何人发言，文责由作者承担。

**方法与工具的边界**：本框架是上述脉络的一次操作化尝试，不是对它们的发展或替代。
