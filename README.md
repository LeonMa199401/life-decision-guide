# 人生决策指南 · Life Decision Guide

有人在一家公司干了八年，工资涨得不多，老板脾气还差，但他就是不走。
你问他为什么不走，他说「习惯了」。

「习惯了」不是原因，是一笔没算完的账。

真正的原因是：他离开的代价，绑在七根看不见的线上——房贷、社保连续性、孩子的学区、配偶的工作、父母的病、行业里的人脉，还有「我是这家公司老员工」这个身份。**拔掉任何一根，其余六根会同时松脱。**

**这套方法只做一件事：把这些线列出来，数清楚，算出每根拔掉要付多少。**

它叫人生决策指南：**72 条判据，全文 5 万字**，做成一个技能包——Claude Code、Codex、WorkBuddy 装进去就能用，对着自己那摊事逐条往下过，不用从头读到尾。

那七根线，一根叫一个**接口**；那根最粗、拔了会连带别的，叫**母口**。

而这几根线连起来，要回答的是三个更大一点的问题：

> **谁控制了你的人生？你是谁的耗材？你该如何破局？**

这三个问题听起来像口号，但在这套框架里，每一个都有可拆的答案——

- **谁控制了你的人生**：不是「某个人」，是那根握着母口的关系。找不出它，就会一直以为是老板、是行业、是命。
- **你是谁的耗材**：看你付出的三笔成本（接入、维持、拔除）最后结算在谁的账上。**只享权利不担责任的，是收租方；只担责任不享权利的，是耗材。**
- **你该如何破局**：先算清插拔成本，再谈走不走。**没算过账的「破局」，多数只是换了个地方当耗材。**

## 它能回答的三类问题

| 你遇到的 | 它给出的 |
|---|---|
| **为什么离不开**——一个人、一群人、一个组织，明明不满意却不走 | 一张接口清单，和每根接口的退出成本 |
| **为什么改不动**——制度改了三次，换了一批人，还是老样子 | 母口定位：到底哪根关系没被碰 |
| **为什么是「总崩」**——有的体系出事是慢慢散，有的是一夜之间全空 | 锁定烈度：接口覆盖度与联保关系 |

## 怎么用：三步

**第一步｜列接口清单**
他一生下来被迫接了哪些（籍贯、户口、阶级出身、性别角色、母语、出生地产业），他自己主动接了哪些（职业、婚姻、平台账号、贷款、社保），哪些正在断、哪些正在长。

> 纪律：只写「他接了什么」，不写「他该不该接」。**把道德问题翻成结构问题，是这一步的全部意义。**

**第二步｜找母口**
在核心资源的生产或分配关系中占支配地位的那根关系。

- **生产型**，以「占有」为标志：血缘 → 人身占有 → 土地 → 资本
- **分配型**，以「卡口」为标志：贸易通道与关税／流量入口与配额／平台分成规则／编制职级分配权

三条检验缺一不可：**它决定「谁能接入、谁的价值被承认」吗？抽掉它，派生关系会随之改向吗？它只是中间环节，还是决定流向与流速？**

**第三步｜算插拔成本**

> 依附强度 ＝ 接口数量 × 单个接口的退出成本 × 接口间联保度

单根接口的四类代价：**身份绑定／沉没成本／生存依赖／观念内化**。
三个追问把账算到底：**维持那笔钱付到第几层**（生存／发展／享乐，三层不可混算）·**拔掉 A，B 会不会同时失效** ·**门外还有几条替代路径**。

**判据一句话：自由不是心态，是插拔成本的函数。**

## 装进 AI 之后，能问什么

装成技能后，你不是「读它」，而是「问它」。以下是两段**示例输出**——不是固定答复，AI 会按你的具体处境重新清点：

### 例一：「我们公司工资不低，但能干的人一批批走，为什么？」

```
【接口清单】
他主动接入的：薪资（中上）、职级（P7 卡三年）、项目主导权、
              期权（四年成熟，还剩两年）、团队里的话语权、行业人脉
出生即绑定：无

【母口】项目主导权 —— 分配型母口（以「卡口」为标志）
  检验①：决定「谁能被看见」，不是次级分配  ✓
  检验②：抽掉它，职级、话语权、期权估值同时失效  ✓
  检验③：不是中间环节，它决定资源流向  ✓

【插拔成本】
  薪资：低（外面给得更高）
  期权：高（未成熟部分归零）
  职级：中（换个地方可能要重新爬）
  项目主导权：低（外面更缺人，反而给得更多）
  联保度：高 —— 期权估值挂钩职级，职级挂钩项目履历，
                三者指向同一处

【结论】不是「钱给少了」，是联保结构把「期权」这一根的成本，
放大成了「职级＋履历」的总成本。能走的人，恰好是联保度最低
的那批——他们手里已经有履历，不需要靠职级兑现。

【什么条件下这个结论会错】期权改为按月成熟，或职级与项目履历
脱钩 —— 那时联保度下降，问题才会真正回到薪资上。
```

### 例二：「这个政策改了三次，为什么落地还是走样？」

```
【接口清单】
执行层的接口：考核指标、财政拨款、人事任免、属地责任、
              上级检查、群众信访
出生即绑定：属地（行政区划决定了他归谁管）

【母口】考核指标 —— 分配型母口
  检验①：它决定「什么算干得好」，进而决定资源与升迁  ✓
  检验②：抽掉它，其余五根接口的权重全部重排  ✓
  检验③：政策文本只是传导，考核指标才决定流向  ✓

【插拔成本】
  不执行政策：低（政策文本有解释空间）
  不完成考核：高（直接影响任免与拨款）
  联保度：高 —— 考核、拨款、任免三根指向同一个上级

【结论】政策改的是文本，没改的是考核。只要考核指标不动，
执行层的最优解永远是「按考核做，按文本说」。

【什么条件下这个结论会错】考核指标被同步改写，或出现一条
与考核脱钩的独立评价通道 —— 那时文本才开始起作用。
```

**它给的不是答案，是「该往哪看」。** 每个结论后面都跟着一句「什么条件下这个结论会错」——这是本框架的写作纪律，也是它和「人生导师」的分界线。

## 72 条判据是什么

上面三步是入口。往里走是一套 **72 条的判据库**，按「原生 → 衍生 → 运行 → 生态 → 增量」排；体系层七律另成一篇，不在 72 条之内：

- **原生六律** 6 条：接口先在、母口（接口第一性）、插拔成本、裸插效应、自我繁殖、悬置
- **衍生六律 ＋ 五条补律** 12 条：倒转、租金（＋暴力底座租、自焊收租两终局）、拜物教、均衡锁、迁移（＋泄压阀四开向、代际转嫁、谣言需求侧）、悬置指数
- **体系层七律** 7 条：身体母口、绕开、竞速拔线、母口自爆、暴力底座、权责分离、筛选收割（收在 `07-体系层七律.md`，另计）
- **生态层与工具** 16 条：公共品律（含恶链共持、成本异质性）、自觉临界，以及 12 条工具——议题生命周期／议程划线／议程汇聚度／链条维／分账／弱者的武器谱／可比性三问／代谢节律尺／双向对照法／参数—口径替换／禁令—授权不对称／留白—裁量
- **判据与补白** 12 条：6 条判据（名分与实权分离、不自觉工具的判定式、出生缺陷、卡口的可维持性、通过权型卡口、改革三出口）＋ 4 条补句 ＋ 2 条补条
- **增量律** 26 条（5.1—5.16）：相位差／话语代谢／焦虑定价｜正当性折旧／承载力／时机｜枢纽／网络切换三阶｜法权接口／暴力担保链／收租位置职能必要性｜尺度同构／代际接口｜路径反噬／判断权垄断｜退出权买断｜责任分置｜风险对价／收租权资本化｜名义主体—实际主体分离｜定价权来源｜成本转嫁｜母口动作谱系｜资产可抓取性｜换手边界｜信用存续期

**合计 72 条**（6 ＋ 12 ＋ 16 ＋ 12 ＋ 26）。

**每一条都带「边界」——它的失效条件。** 引用时请连边界一起引：剪掉边界，判据会退化成口号。

## 这不是什么

| 不是 | 为什么 |
|---|---|
| 不是万能解释框架 | 用它解释一切，它就变成了新的拜物教。**律可以加，根不能丢。** |
| 不是道德判断 | 它解释「为什么」，不判「好不好」。 |
| 不是行动指南 | 它说明约束在哪，不说明该做什么——后者需要价值判断。 |
| 不是学术著作 | 没有文献综述与学派定位，只有判据与边界。 |

## 怎么装

**Claude Code / Codex**：把整个目录放进 skills 目录即可。

```
your-project/.claude/skills/life-decision-guide/
├── SKILL.md
└── references/
```

**WorkBuddy**：放进用户级技能目录，所有项目可用；只想在单个项目里用，就放项目级。

```
~/.workbuddy/skills/life-decision-guide/     # 用户级
<项目>/.workbuddy/skills/life-decision-guide/  # 项目级
```

`SKILL.md` 的 frontmatter 按 WorkBuddy 开放平台的字段写（`name`／`display_name`／`description`／`version`／`author` ＋ 中英示例），直接放进去即可识别，不需要改字段。

**目录名必须与 `SKILL.md` 里的 `name` 一致**（`life-decision-guide`）——中文名是给人看的标题，`name` 字段只接受小写字母、数字与连字符，写成中文会装不上。

**直接读**：`references/00-索引.md` 是按问题排的检索表，`01-律目全谱.md` 是全部判据正文。

**只要一张纸**：`references/02-操作判据.md` 里有三问、五问、六种误读，五分钟看完，**大多数场合这一页就够用**。

## 五个词

| 词 | 意思 |
|---|---|
| **接口** | 一段社会关系。**接口是关系，不是实体**——土地、资本、劳动是载体，不是接口本身。 |
| **母口** | 在核心资源的生产或分配关系中占支配地位的那根。生产型看「占有」，分配型看「卡口」。 |
| **插拔成本** | 接入、维持、拔除三笔账。**自由不是心态，是插拔成本的函数。** |
| **悬置** | 旧口已拔、新口未成。断档期的焦虑是结构问题，不是性格问题。 |
| **联保度** | 拔掉 A，B 会不会同时失效。**联保把单根成本放大成总成本。** |

## 这套东西从哪来

它长在三支脉络上：

1. **马克思**关于「人的本质是一切社会关系的总和」的命题，以及生产关系、剩余价值与地租的分析；
2. **列宁**关于帝国主义、国家与暴力的分析，以及米歇尔斯关于组织寡头化的论断；
3. **当代中国民间思想场域**——若干长期参与社会观察与讨论的写作者，在关于成本、分配、政策与产业的分析中提出的判断。

第三支的思想增量，观点已经过提炼与改写，**表述一律做了匿名化处理**；本框架不代任何人发言，文责由作者承担。

**方法与工具的边界**：这是上述脉络的一次操作化尝试，不是对它们的发展或替代。
