# 操作判据 · 三问、五问与六种误读

> 全谱系 72 条律是「库」，这个文件是「口」——真正上手时，只用这里的几组问句。

## 一、三问：拆解别人

1. **这个人／这群人，一生下来接了几个接口？**（列接口清单，出生即绑定的单列一组）
2. **每个接口的插拔成本是多少？**（接入＋维持＋拔除，三笔账分开算）
3. **这是新接口，还是旧母口的自我繁殖？**（查谱系：它在保护谁、服务哪个母口）

**三问问社会，五问问自身。**

## 二、五问：安顿自己

决策前先定位，再谈策略。顺序不可颠倒。

1. **列清单**：我现在被插在哪些接口上？（收入／身份／关系／观念，四类各是什么）
2. **找母口**：哪根是第一性的？谁握着它？（收入最终靠谁／身份谁给／替谁打工）
3. **算成本**：每根接口的插拔成本多少？（接入＋维持＋拔除）
4. **查谱系**：我最近的变化，是新接口长出来，还是旧母口在繁殖？（加薪是技能涨了，还是平台红利？）
5. **判悬置**：我是不是在断档期？（拔了几根、插上几根、缺口在哪）

> 顺序的意义：**先看清自己站在哪个架子上，再决定抽哪把刀。**

## 三、六种误读及其反驳

这套框架最容易被读成的六个样子，以及为什么不对。

| 误读 | 反驳 |
|---|---|
| **接口决定论**（取消能动性） | 接口可迁移、可自建、可集体拆除。自觉是规律的自觉运用，不是对规律的否定。 |
| **技术化还原**（把阶级剥削还原成技术问题） | 接口是**转译工具**，不是本体论替代。母口的本质仍然是生产方式与生产资料归属。 |
| **静态清单化**（列完就完事） | 清单是活的：须「试拔」验证，须按悬置指数动态重算。 |
| **个人主义误读**（＝精致利己） | 落点是接口共同体。**看清共享的母口，才有集体行动的可能。** |
| **悬置指数伪精确** | 它是**近似算账**（粗账）。价值在「把焦虑转成清单」这个动作本身，不在小数点。 |
| **体系膨胀／接口一元论** | 用它解释一切，它就变成了新的拜物教。 |

### 关于第六种：三道防线

框架越扩越大时，最容易犯的就是这个。三条防线：

1. **分级**：核心律是骨架；补白方向不与之并列竞争；体系层七律内部再分「五条独立律位 ＋ 两条作为租金论展开」。
2. **分源**：外来的思想增量只取「符合唯物史观」的那一刀，不整体照搬。
3. **守根**：**新增的律必须能翻译回「人与人的关系」；翻不回去，就是过度扩张。**

**判定句**：**接口论是转译工具，不是新本体论；律可以加，根不能丢。**

## 四、四条使用纪律

1. **命中不足三条 → 说「无对口判据」。** 硬套比不用更糟。
2. **引用必带边界。** 每条律的 `[边界]` 是它的失效条件；剪掉边界，判据会退化成口号。
3. **结构分析不产出行动建议。** 它说明约束在哪，不说明该做什么——后者需要价值判断。
4. **母口判定必须过三检验。** 凭印象指认母口，是本框架最常见、也最伤人的一种误用。

## 五、一个完整走通的例子

**问题**：某平台的商家明知抽成高，为什么还是不走？

| 步 | 内容 |
|---|---|
| **列清单** | 流量入口、支付通道、履约物流、评价信用、员工用工、经营贷。出生即绑定：无。 |
| **找母口** | **流量入口——分配型母口**（以「卡口」为标志）。三检验：①决定谁能被看见 ✓；②抽掉它，评价／履约／贷款同时失效 ✓；③不是中间环节，决定流向与流速 ✓。 |
| **算成本** | 单根退出成本中（换平台要重建评价与客源）；**联保度高**——评价、履约、贷款都指向同一个流量坐标，拔一根则其余同时贬值；门外替代路径有限（同等流量的入口只有两三个）。 |
| **查谱系** | 平台不断长出的新规则（保证金、服务分、专属客服），是**新接口**还是**旧母口的繁殖**？→ 多数是繁殖：都在加固同一个流量卡口。 |
| **判悬置** | 不适用（商家不是在断档期，是在锁定态）。 |

**结论**：不是商家「不理性」，是**联保结构把单根成本放大成了总成本**。

**这个结论在什么条件下会错**：出现第二个同等流量的入口，且评价可以跨平台迁移。——**写出反驳条件，结论才算成立。**
