# 示例集

这里放的是**走通的样例**，不是标准答案。

## 怎么读这些示例

**别把它们当结论看，当格式看。** 每份示例展示的是四件事：

1. **接口清单怎么列**——尤其是「出生即绑定」那一组，多数人漏掉它
2. **母口怎么判**——必须过三检验，凭印象指认是这套框架最伤人的误用
3. **插拔成本怎么算**——接入、维持、拔除，三笔账分开
4. **反驳条件怎么写**——每个结论后面必须跟一句「什么条件下这个结论会错」，否则结论不算成立

**这些数字全是编的。** 示例里的人、事、金额都不是真实案例，只保证结构对得上。你要用自己的数去套一遍，才能得到你的结论。

## 一个提醒

**结构分析不产出行动建议。** 它说明约束在哪、哪根是母口、拔了要付多少；它不说明你该做什么。最后那一步要你自己拍板，因为那涉及你要什么——那不是算账能算出来的。

## 关于示例里的判据引用

每份示例末尾用 `引用` 一行列出用到的判据编号，方便回 `references/01-律目全谱.md` 查原文。**编号对不上就是示例写错了，不是判据写错了**——遇到这种情况开个 issue。
