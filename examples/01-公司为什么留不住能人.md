# 例一：我们公司工资不低，但能干的人一批批走，为什么？

> 这是「三问」的用法：拆别人，不拆自己。
> 场景：HR 或管理者视角，看着团队里最能干的人接连离职，涨薪也留不住。

## 走一遍

```
【接口清单】
他主动接入的：薪资（中上）、职级（P7 卡三年）、项目主导权、
              期权（四年成熟，还剩两年）、团队里的话语权、行业人脉
出生即绑定：无

【母口】项目主导权 —— 分配型母口（以「卡口」为标志）
  检验①：决定「谁能被看见」，不是次级分配  ✓
  检验②：抽掉它，职级、话语权、期权估值同时失效  ✓
  检验③：不是中间环节，它决定资源流向  ✓

【插拔成本】
  薪资：低（外面给得更高）
  期权：高（未成熟部分归零）
  职级：中（换个地方可能要重新爬）
  项目主导权：低（外面更缺人，反而给得更多）
  联保度：高 —— 期权估值挂钩职级，职级挂钩项目履历，
                三者指向同一处

【结论】不是「钱给少了」，是联保结构把「期权」这一根的成本，
放大成了「职级＋履历」的总成本。能走的人，恰好是联保度最低
的那批——他们手里已经有履历，不需要靠职级兑现。

【什么条件下这个结论会错】期权改为按月成熟，或职级与项目履历
脱钩 —— 那时联保度下降，问题才会真正回到薪资上。
```

## 三个判断是怎么下的

**为什么母口是「项目主导权」而不是「薪资」？**

因为它过了三检验。第一检验问：它是不是决定「谁能被看见」的那一根？主导权决定项目分配，项目决定履历，履历决定外部定价——是。第二检验问：抽掉它，别的接口会不会同时失效？会——没有主导权就没有可写的履历，没有履历职级就兑现不了，期权估值也跟着掉。第三检验问：它是中间环节还是决定流向？它决定流向。

薪资过不了这三条：抽掉薪资，职级、话语权、人脉都还在，只是便宜了一点。

**为什么「联保度」比单根成本更重要？**

因为**能走的人不是按单根成本算的，是按总成本算的**。期权这一根单独看成本很高（未成熟归零），但如果它只影响钱，很多人会忍；它真正的作用是把职级和履历一起绑住了——想兑现期权就得先熬职级，想熬职级就得继续拿项目，想拿项目就不能走。三根指向同一处，拔一根等于拔三根。

反过来，联保度最低的那批人恰好是最容易走的：他们手里已经有可对外证明的履历，不需要靠这家公司的职级来兑现。**所以「留不住能人」这个现象，本身就是联保结构在起作用——它专留那些还离不开的人。**

**为什么结论后面必须跟一句「什么条件下会错」？**

因为这套框架给的是**条件判断**，不是定律。这个结论成立的前提是“期权估值挂钩职级、职级挂钩项目履历”这条链还在。一旦期权按月成熟（成本从“归零”变成“按比例到手”），或者职级跟项目履历脱钩（履历可以独立认证），这条链就断了，问题才会真正回到薪资上。

**不写这一句，结论就变成了「所有留不住人的公司都是联保结构问题」——那是错的。**

## 这类问题的通用问法

遇到「为什么留不住人／为什么招不到人／为什么优秀的人反而不被提拔」，按这个顺序问：

1. 他主动接入了哪几根？（薪资、职级、主导权、期权、话语权、人脉……）
2. 哪一根决定「谁能被看见」？（这一根通常是母口，往往不是薪资）
3. 抽掉母口，有几根会跟着失效？（≥2 根说明联保度高）
4. 最容易走的是哪批人？他们的联保度是多少？

第 4 问是关键：**如果最容易走的恰好是最能干的那批，说明这套结构在系统性地驱逐高能力者，而不是在挽留他们。**

## 引用

- **原生律三·插拔成本律**——接入、维持、拔除三笔账分开算
- **衍生律四·均衡的接口锁**——多根接口指向同一处时，单根成本被放大为总成本
- **5.3 一·接口枢纽律**——分配型母口的识别判据（三检验）
- **5.7 一·退出权买断律**——为什么“能走”这件事本身也是一种权利

**边界**：本示例的结论依赖「期权—职级—履历」这条链的存在。在期权可按月成熟、或履历可独立认证的组织里，同样的分析会得出不同结论——那时要重新找母口，不能照搬。
