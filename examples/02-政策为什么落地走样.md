# 例二：这个政策改了三次，为什么落地还是走样？

> 同样是「三问」，对象换成了制度与执行层。
> 场景：政策文本反复修订，执行效果始终不达预期，修订者困惑「该改的我们都改了」。

## 走一遍

```
【接口清单】
执行层的接口：考核指标、财政拨款、人事任免、属地责任、
              上级检查、群众信访
出生即绑定：属地（行政区划决定了他归谁管）

【母口】考核指标 —— 分配型母口
  检验①：它决定「什么算干得好」，进而决定资源与升迁  ✓
  检验②：抽掉它，其余五根接口的权重全部重排  ✓
  检验③：政策文本只是传导，考核指标才决定流向  ✓

【插拔成本】
  不执行政策：低（政策文本有解释空间）
  不完成考核：高（直接影响任免与拨款）
  联保度：高 —— 考核、拨款、任免三根指向同一个上级

【结论】政策改的是文本，没改的是考核。只要考核指标不动，
执行层的最优解永远是「按考核做，按文本说」。

【什么条件下这个结论会错】考核指标被同步改写，或出现一条
与考核脱钩的独立评价通道 —— 那时文本才开始起作用。
```

## 三个判断是怎么下的

**为什么「出生即绑定」这一组要单列？**

因为属地这一根**不是他选的**。政策可以改、岗位可以换、考核指标可以调，但行政区划决定了他归谁管、出了事谁负责、钱从哪来——这一根在他进入这个体系时就已经插好了，无从拔除。

单列这一组的意义在于：**它揭示了哪些约束是不能谈判的**。多数「为什么执行不了」的分析，都在讨论可谈判的部分（资源、人力、意愿），忽略了不可谈判的部分（管辖权、责任归属）。而后者往往才是真正的天花板。

**为什么母口是「考核指标」而不是「政策文本」？**

因为政策文本**不决定流向**。它规定“应该做什么”，但不规定“做不好会怎样”。而考核指标直接连着任免与拨款——它规定“什么算做好”以及“做不好的后果”。

第三检验（是不是中间环节）在这里区分得最清楚：政策文本是传导环节，考核指标是决定环节。**改文本不改考核，等于改了说明书没改电路。**

**「按考核做，按文本说」这句话的机制是什么？**

是两套接口的优先级不同。执行层同时面对两根接口：一根是政策文本（低插拔成本——解释空间大，不照做通常不会有直接后果），一根是考核指标（高插拔成本——直接挂钩任免与拨款）。

**当两根接口给出不同指令时，理性选择是服从成本高的那根，同时用低成本那根的语言来表述。** 这不是道德问题，是接口权重问题。所以修订者看到的“走样”，在执行层看来是**精确执行**——他们精确执行的是考核，不是文本。

## 这类问题的通用问法

遇到「为什么好政策落不了地」「为什么制度设计得很好却执行走样」「为什么 KPI 定了还是没用」，按这个顺序问：

1. 执行层实际被插在哪些接口上？（别列“应该有的”，列“真在起作用的”）
2. 哪一根决定“什么算干得好”？
3. 政策文本和考核指标，给出的指令一致吗？
4. 如果不一致，服从哪一根的成本更高？

第 4 问是核心：**答案几乎总是考核。** 所以第 5 问才是关键——

5. **考核指标改了吗？** 没改，那么这次修订的效果上限就是“说法变了，做法不变”。

## 一个容易搞反的地方

有人把这条读成「执行层阳奉阴违」或「体制僵化」，这是误读。**这套框架不产出道德判断。**

真正的问题在于：**设计者以为自己在改一根接口，实际上改的是另一根。** 政策文本是“名义主体”，考核指标是“实际主体”——两者分离时，改前者不产生任何行为变化。这正是框架里「名义主体—实际主体分离律」在起作用。

**换句话说，走样的不是执行，是设计者对“自己在改什么”的判断。**

## 引用

- **原生律二·接口第一性**——决定流向的那一根，优先于传导的那一根
- **原生律三·插拔成本律**——执行层按成本高低选择服从对象
- **5.3 一·接口枢纽律**——分配型母口的识别判据（三检验）
- **5.10 一·名义主体—实际主体分离律**——文本是名义，考核是实际
- **5.12 一·成本转嫁律**——修订成本由谁承担，决定修订能走多远

**边界**：本示例的前提是「考核指标独立于政策文本、且由同一上级掌握」。若考核指标与政策文本同步改写，或存在与考核脱钩的独立评价通道（例如第三方评估、服务对象直评），结论失效——那时文本才开始真正起作用。
