# 例五：该不该去考公？

> 「五问」的第三种用法。
> **这份示例要拆的是一个说法：「我想要稳定」。**

## 一个具体的处境

> 27 岁，省会城市，私企做运营，月薪 1.1 万，加班常态。父母反复劝考公，自己也动过念头。纠结的是：现在的工作学得到东西，但看不到四十岁以后。

## 第一问：列清单

| 接口 | 现在（私企） | 考上之后（编制） | 类型 |
|---|---|---|---|
| 收入 | 1.1 万，可涨 | 5—6 千起，涨幅固定 | 收入 |
| **可解雇性** | 高（随时可能失业） | **低（非重大过错不可解雇）** | 制度 |
| 社保与退休待遇 | 一般 | 强 | 制度 |
| 专业能力的市场价值 | 逐年积累 | **多数岗位不积累，且会折旧** | 能力 |
| 地域自由 | 高（可换城市） | **低（分配定岗，调动困难）** | 制度 |
| 时间支配 | 差（加班常态） | **基层可能更差** | 时间 |
| 社会评价与婚恋议价 | 中 | 高（尤其在本地） | 观念 |
| 晋升通道 | 不确定但有空间 | 可预期但有封顶 | 身份 |

**注意两件事：**

第一，**“稳定”这个词在表里没有对应行**。它不是一个接口，它是「可解雇性」这一根的表现。

第二，**“时间支配”这一行常被搞反**。多数人以为体制内清闲，但基层岗位的实际工作强度可能高于私企，只是性质不同（可预期 vs 不可预期）。

## 第二问：找母口

**候选一：稳定。**
“稳定”过不了三检验——它不是接口，是一种感受。问它“抽掉它别的会不会失效”，问不下去。

**候选：编制。**

> **母口＝「编制」这一根。**

过三检验：
① 抽掉编制，别的接口会怎样？——可解雇性、社保退休待遇、地域调配资格、社会评价、婚恋议价，**五根同时失效**。✓
② 它决定其他接口的存续条件吗？——是。那些待遇不是“岗位好”，是“编制”给的。同一间办公室里，编制内外做同样的活，待遇可以差一倍。**✓**
③ 它是中间环节还是决定流向？——决定流向。**✓**

**母口＝编制。**

这个判定把问题彻底改写：
- 如果母口是“稳定” → 问题是“我要不要稳定”——这是个情绪问题，永远答不完
- 如果母口是“编制” → 问题是“**我愿意用哪几根接口，去换编制这一根**”——这是个交易问题，可以算

## 第三问：算成本

**编制不是免费的。它要你用几根接口去换。**

| 让出的接口 | 让出多少 | 可逆吗 |
|---|---|---|
| 专业能力的市场价值 | 大：多数体制内岗位不积累可迁移技能，五年后市场定价能力下降 | **基本不可逆**（超过 30 岁再出来，履历会打折） |
| 地域自由 | 大：定岗后调动困难，跨省尤难 | 低 |
| 收入上限 | 中：起薪低，涨幅固定，但下限高且不会断 | 可逆（但回去也晚了） |
| 时间支配 | 不确定：基层可能更紧，只是可预期 | 中 |
| 试错机会 | 大：一次考上定终身，中间年份的机会成本高 | **不可逆**（年龄是硬门槛） |

| 换来的接口 | 值多少 |
|---|---|
| 不可解雇 | 高：这是编制最核心的价值，其他都是它的衍生 |
| 社保与退休 | 高：长期看是最大的一笔 |
| 社会评价与婚恋议价 | 中到高：地域差异极大，本地尤其显著 |
| 可预期的路径 | 中：知道五年后大概在哪个位置，这本身是一种价值 |

**关键：这笔交易的大部分成本是不可逆的，大部分收益是长期的。** 这解释了为什么纠结：**成本马上付，收益二十年后才兑现**——和买房、读博是同一个收支结构。

## 第四问：查谱系

**问：想要编制，是新长出来的接口，还是旧母口在繁殖？**

四种常见形态，分辨方法各不相同：

1. **风险厌恶型**——真的承受不了不确定性。这是真实的新接口。检验：过去三年你有没有因为一次裁员或行业波动而实质性受损？有，这根是硬的。
2. **父母期待型**——不是你想要，是父母想要。检验：如果父母完全支持你的任何选择，你还考吗？
3. **同辈比较型**——同学都考上了。检验：如果没人知道你的选择，你还选同一个吗？
4. **退路型**——不是想去，是现在这条路走不通了。检验：如果现在的工作涨薪 50%，你还考吗？

**第 4 种最危险**，因为它看起来最像“理性决策”，实际上是“逃避性迁移”。特征是：说不出编制具体好在哪，只说“总比现在强”。

**分辨的意义：前三种考上了也会后悔，第四种考上了会二次动摇。**

## 第五问：判悬置

**这一问在考公这件事上有一个特殊形态：它可能是两次决策，不是一次。**

- **第一次**：考不考（现在做的这个决定）
- **第二次**：考上之后待不待得住（三到五年后的决定）

**多数人只做第一次决策，把它当成终点。** 但真正的问题是第二次——因为：

> **考上之后，你的母口变了。**

进去之前，母口是编制（你还没有）；进去之后，母口变成**“编制内的资历”**——晋升要熬年限、调动要看关系、评优要看排队。**这时候你会发现，自己又回到了一个“必须等、必须熬”的结构里，只是换了一套规则。**

所以在做第一次决策前，必须先问第二次的问题：**五年后我如果不想待了，那时候我还有别的接口吗？**

- 如果答案里有（技能还在、存款够、有副业）→ 这次交易是可逆的，可以试
- 如果答案是“没有”→ 这次交易不可逆，要想清楚

**悬置期的判断**：如果你现在已经在“半脱离”当前工作（不投入、不学习、不规划），同时“半接入”备考（买了书、报了班），那么你处在悬置期。**悬置期的人容易把“逃离当前处境”误认为“选择新方向”。**

## 这份示例给出了什么

- 你要问的不是“要不要稳定”，是“**愿意用哪几根换编制**”
- 这笔交易的成本不可逆、收益长期——所以纠结是理性的，不是软弱
- 你的动机可能是四种之一，其中“退路型”最危险
- 这是**两次决策**，而多数人只做了第一次

**它没告诉你该不该考。因为“你要什么”这件事——是想要确定性，还是想要可能性——判据算不出来。**

## 引用

- **原生律三·插拔成本律**——注意区分“可逆成本”与“不可逆成本”
- **原生律二·接口第一性**——编制是母口，待遇是它的表现
- **原生律六·接口悬置律**——半脱离＋半接入＝悬置期
- **衍生律二·接口租金论**——编制本质是一种受保护的收租位置
- **5.3 一·接口枢纽律**——母口识别三检验
- **5.6 一·成功路径反噬律**——考上之后的“熬资历”结构，是一种新的锁定

**边界**：本示例的母口判定依赖「编制与岗位待遇强绑定」。在部分市场化程度较高的岗位（如聘任制公务员、事业单位合同制），编制与待遇的绑定较弱，母口可能是“岗位本身”或“地域”——那时要重新判定。
